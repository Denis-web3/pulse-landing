# PULSE

Адаптивный лендинг PULSE, созданный с использованием HTML, CSS и JavaScript.

## Описание проекта

Проект представляет собой одностраничный сайт с современным дизайном, адаптивной вёрсткой и интерактивными элементами. Страница включает навигационное меню, секции с информацией о проекте, формы связи и футер.

## Технологии

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Структура проекта

- `index.html` — главная страница
- `css/` — стили проекта
- `js/` — скрипты проекта
- `fonts/` — шрифты
- `icons/` — иконки
- `images/` — изображения

## Запуск проекта

1. Скачайте или склонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
